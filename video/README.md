# Ролики про Hark

Четыре сборки: русский и английский, широкий и вертикальный.

```bash
npm install
npm run render:all
```

Готовое ложится в `out/`. Одна сборка занимает около минуты.

| Композиция | Кадр | Куда |
|---|---|---|
| `Ru` | 1920×1080 | Телеграм в развёрнутом виде, YouTube |
| `En` | 1920×1080 | Reddit, YouTube |
| `RuTall` | 1080×1920 | Телеграм, короткие форматы |
| `EnTall` | 1080×1920 | короткие форматы |

Посмотреть и подвигать по кадрам: `npm run studio`.

## Ролик должен читаться без звука

И Телеграм, и Reddit проигрывают видео беззвучно, пока в него не ткнут. Поэтому
весь смысл несёт текст, а сцены идут по восемь-девять секунд: столько нужно,
чтобы успеть прочитать. Музыка здесь приятная добавка для площадок, где звук
включён, и без неё ролик работает целиком.

## Как добавить музыку

1. Возьмите трек с [Pixabay](https://pixabay.com/music/). Их лицензия
   разрешает коммерческое использование и не требует ссылки на автора; нельзя
   только перепродавать сам файл отдельно от работы. Скачивание требует
   учётной записи.
2. Положите файл в `public/music.mp3`.
3. В `src/Root.tsx` поставьте `withMusic: true` у нужных композиций.
4. Пересоберите.

Громкость стоит на 0,45 в `src/Video.tsx`: под текст громче не нужно. Ролик
длится 45 секунд, так что трек короче придётся зациклить, а длиннее обрежется
сам.

Что искать: minimal techno, ambient techno, «tech background». Подойдёт
что-нибудь ровное без вокала и без резкого вступления — первые пять секунд
играют под число, и барабанная сбивка там перетянет внимание на себя.

## Числа в кадре настоящие

Чек в сцене про деньги взят из демонстрационной базы Hark целиком: два
обращения к модели, один запрос в базу, 518 токенов вывода, из них 448
рассуждения. Проверить можно так:

```bash
sqlite3 hark.db "SELECT completion_tokens, reasoning_tokens, steps FROM receipts"
```

Ответ пробы в сцене про модель — тоже настоящий, `gpt-5-nano` отвергает
`temperature` и `max_tokens`. Если будете править текст в `src/copy.ts`,
держите эту связь: ролик про честный счёт, и выдуманное число в нём отравляет
всё остальное.

## Устройство

```
src/copy.ts       весь текст, два языка рядом
src/theme.ts      палитра и длительности сцен
src/components/   общий каркас кадра
src/scenes/       шесть сцен
src/Root.tsx      четыре композиции
```

`node_modules` вынесен на диск E: через junction — на C: не хватает места.
Если разворачиваете у себя, просто удалите ссылку и поставьте заново.
